# Personal-site fonts

Self-hosted copies of the original personal website's Archivo headings and Space Grotesk body text. Downloaded on 10 October 2026 from the font authors' official repositories. No font network requests are made during build or by visitors.

- Archivo: [Omnibus-Type/Archivo](https://github.com/Omnibus-Type/Archivo/tree/211127690e8ff106c36c935f7e5e697114cff103), revision `211127690e8ff106c36c935f7e5e697114cff103`, original paths `fonts/webfonts/Archivo-Regular.woff2` (400), `Archivo-Bold.woff2` (700), `Archivo-Black.woff2` (900). Normal styles only.
- Space Grotesk: [floriankarsten/space-grotesk](https://github.com/floriankarsten/space-grotesk/tree/03507d024a01282884232081fc6011c09ff4e849), revision `03507d024a01282884232081fc6011c09ff4e849`, original path `fonts/woff2/SpaceGrotesk[wght].woff2`, variable weight 300–700, normal style.

Font bytes are unchanged; local filenames differ. Both use SIL Open Font License 1.1. Full upstream copyright/license notices are included unchanged in Archivo-LICENSE.txt and SpaceGrotesk-LICENSE.txt. Keep these notices with redistributed font files. The personal website and engineering portfolio both use these fonts, with separate scoped font variables and visual systems. Geist remains the shared fallback and monospace face.
